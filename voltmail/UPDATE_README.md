# Update Instructions

## Version Note
This version includes performance optimizations and overall system improvements for better stability and speed.

## How to Update
You can update directly from your existing installation:

1. Go to your system **Settings**
2. Click the **"Update"** button
3. Then Click **Manual Update** tab and Upload update zip, once success message then clear the cache 
4. For version 4.1 replace vendor full directory to src(you can find vendor folder in installer zip)

That's it � the update will be applied automatically.
